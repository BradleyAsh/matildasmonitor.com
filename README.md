# Matildas Monitor

Source for [Matildas Monitor: Australian Women's Football Player Database](https://www.matildasmonitor.com/), a public, searchable database of Australian women's footballers across the A-League Women, NPL Women's and overseas professional leagues.

Scouting reports are published on [Substack](https://substack.com/@matildasmonitor).

## Stack

- Static site on GitHub Pages, custom domain via CNAME
- Player database served as a Looker Studio embed from a Google Sheet master record
